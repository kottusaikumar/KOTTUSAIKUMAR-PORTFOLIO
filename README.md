# Kottu Saikumar — Portfolio

A single-page, scroll-driven portfolio site (TanStack Start + React +
Three.js + GSAP). This README is a map of the project — start here if
you're new to the codebase and want to know **where to make a change**.

## Quick orientation

| I want to...                                         | Go to                                                |
| ---------------------------------------------------- | ---------------------------------------------------- |
| Edit project/experience/skills text or links         | `src/data/`                                          |
| Change a section's colors or layout                  | `src/styles/portfolio.css` (search the section name) |
| Change the nav, hero, or how sections are assembled  | `src/components/sections/`                           |
| Change one section's animated 3D/particle background | `src/components/scenes/`                             |
| Add/replace a video, image, or other static file     | `public/`                                            |
| Change the route / page shell / `<head>` tags        | `src/routes/`                                        |

## How a section is put together

Every section (Skills, Experience, Process, About, Projects, Proof,
Contact) is composed the same way, from three separate places:

1. **Content** — a plain data array in `src/data/` (e.g. `experience.ts`).
2. **Animated background** — a small component in `src/components/scenes/`
   that mounts a Three.js scene (e.g. `ExperienceField.tsx`), imported and
   dropped into the section's JSX.
3. **Layout + color** — the section's markup lives in
   `src/components/sections/Portfolio.tsx`, and its visual styling lives in
   `src/styles/portfolio.css` (search for the section's name — the file's
   table of contents at the top points to every relevant block).

`Portfolio.tsx` itself stays one file rather than one-component-per-section,
because most of it is wired to a single shared animation effect (smooth
scroll, the background color crossfade, section-transition wipes, scroll
reveals) that operates across the whole page at once —
see the comment at the top of that file for the full reasoning.
