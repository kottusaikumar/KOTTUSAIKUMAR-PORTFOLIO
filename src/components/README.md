# src/components

| Folder      | Contains                                                                                                                                                                                                                                                                     |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sections/` | The actual portfolio page — hero, nav, and every scroll section. See `sections/README.md`.                                                                                                                                                                                   |
| `scenes/`   | One small component per section's animated Three.js background. See `scenes/README.md`.                                                                                                                                                                                      |
| `ui/`       | Generic shadcn/ui primitives (button, dialog, toast/`sonner`, etc.) generated by the project scaffold. Not portfolio-specific — these are only referenced by `sections/Portfolio.tsx` where a generic UI piece (like the toast notifications on the contact form) is needed. |
