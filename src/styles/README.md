# src/styles

| File            | What it is                                                                                                                                                                         |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `portfolio.css` | All visual styling for the portfolio site: design tokens, the header/nav, hero, and every section's layout + color palette. Imported once, by `components/sections/Portfolio.tsx`. |

This is deliberately **one file** rather than one-per-section. A lot of
per-section styling is defined in two places by design — a base layout
block, and a later, higher-specificity "color world" override — and later
rules in the cascade intentionally win. Splitting the file into separate
per-section stylesheets would risk silently changing that load order (and
therefore the final colors) in a way that's very easy to get wrong and
hard to visually catch.

Instead, the file opens with a table of contents comment mapping out every
major block (design tokens, reset, header, hero, each section's base
layout, the section-transition curtains, and each section's color-world
override) — search for the section name and you'll land in the right
place.

Note: `src/styles.css` (one level up, **not** in this folder) is a
different file — it's the Tailwind/shadcn base stylesheet generated by the
project scaffold, unrelated to this site's actual design.
